About the Event

Faculty Tech Innovation Day 2026 is a one-day technology event organised for university students to explore programming, cybersecurity, software development and current technology trends.

Web Development Workshop

This workshop introduces students to modern web development concepts and demonstrates how websites are structured using HTML and other web technologies.

Cybersecurity Awareness Session

This session introduces common cybersecurity threats and explains how students can protect their personal information and online accounts.
